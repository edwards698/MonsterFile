# MonsterFile
###  Rename images faster. Work smarter. Stay local.
A fast, beautiful, local-first batch image renaming tool built for macOS. No cloud, no subscription, no telemetry. Your files never leave your Mac.
##
![alt text](Boom_1.png)
# Files 
### Features
* ```Batch rename``` — Rename entire folders of images at once with a custom prefix and sequential numbering

* ```Live preview``` — See exactly what every file will be called before you commit

*  ```Grid & List view``` — Switch between a detailed list table and a visual thumbnail grid

* ```Image preview ```  — Click any file to open a full-size lightbox with keyboard navigation

* ```File metadata bar``` — Hover any row to see name, type, size, modified date and new name

* ```Fully local``` — No internet required. Files never leave your computer

* ```AI Agent``` (coming soon) — Smart AI-powered renaming assistant

##  How to Use
 
### Rename a folder of images
 
1. Click  Add ```Folder```  in the toolbar
2. Click the ```T``` icon → type your prefix (e.g. `holiday`, `product`, `client`)
3. Click the ```#``` icon → set the start number if needed
4. Toggle ```0``` to enable leading zeros (e.g. `img_001` instead of `img_1`)
5. Check the **New Name** column — the preview updates live as you type
6. Click **✓ Save Changes** to rename all files on disk
